# Outputs

Deliverables and session records live here. Four kinds of file:

1. **`kb-registers.md`** — the standing index: change-log entries (newest first), the
 processed-items log for everything ever seen in `Raw/`, wiki structure changes, and outputs
 produced. Read before starting any session (`../CLAUDE.md` §0).
2. **`change-log-YYYY-MM-DD-<slug>.md`** — one file per session, written once and never edited
 again; superseded content gets a new dated file, not an edit to an old one.
3. **`Correspondence/`** — a filed copy of every document registered under this KB's scope on the
 shared group Document Register (prefix `FA`), named `<ID> - <Category> - <Short Title>.<ext>`.
4. Any other deliverable produced for the owner (a report, a drafted letter, an export) — filed
 here directly and recorded in `kb-registers.md`'s "Outputs produced" table.
