# Correspondence

Filed copy of every document that is in scope for this KB (workshop machinery — invoices,
manuals, warranty letters, service reports, compliance certificates) and has been registered on
the **Fishbone Group Document Register** (Smartsheet sheet `7352854736144260`) under AMFA
Furniture Ltd's own `FA` prefix. See `../../CLAUDE.md` §1 for the numbering convention.

Naming: `<ID> - <Category> - <Short Title>.<ext>`, e.g.
`FA0000012 - Machinery-Warranty - SCM CNC Router Warranty Certificate.pdf`.

Currently empty — nothing has been registered yet. A document must already exist in `../../Raw/`
and be read/extracted into the Wiki before a copy is filed here; this folder is the filed record,
not the inbox (that's `Raw/`).
