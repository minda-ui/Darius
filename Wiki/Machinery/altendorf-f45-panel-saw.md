# Altendorf F45 ElmoDrive — Sliding Table Saw

The workshop's second registered machine (asset code `FA2303`): a CNC sliding-table (panel) saw
made by Altendorf GmbH, Germany — part of the same Altendorf Group that Hebrock (`FA2301`) belongs
to. Cuts wood, wood-based/similar materials (chipboard, fibreboard, plywood, veneer, gypsum
plasterboard, cardboard, cork, light metal e.g. aluminium, dimensionally stable plastics). Fitted
with the "ElmoDrive" CNC touchscreen control unit, which has its own separate operating manual.
Manufacturer contact and ordering details: `Wiki/Suppliers/altendorf-gmbh.md`.

**Three documents, one machine.** The 12 PDF parts in `Raw/` are three distinct documents:
- **Main machine manual** (parts 1-6): doc 0000010074-011-2023 GB, "Version 03/2023". Three
  duplex-scan pairs (odd-ascending + even-descending), reconstructing pages 1-74, 75-124, 125-183.
- **ElmoDrive control-unit manual** (parts 7-8): doc 0000010077-001, "Version 09/2019" cover /
  "0000010077-001-2020GB" footer.
- **Spare parts manual** (Spare parts manual parts 1-4): doc 0000010101-006-2023 DE, "Version
  08/2023," titled "Beidseitige Schwenkung / Two-way tilt" — confirms this machine's tilt variant.
  Parts 1-2 are a duplex pair (pages 2-98); parts 3-4 are very likely a second duplex pair covering
  pages ~99-147, though which of the two carries the odd vs. even sequence couldn't be confirmed
  from OCR alone — the content itself is fully captured either way.

## The 2026 move — and what it implies

**The workshop moved from Unit 32 to Unit 31.** The lease for Unit 31 (Forth England Limited to
Furniture by Fishbone Limited, the company's name before it became AMFA Furniture Ltd on 13 July
2026) is **dated 25 June 2026**. The lease date is not necessarily the date the machines were
physically moved, and no record of the move itself exists anywhere in this KB.

**Of the three machines this one has the most to re-establish after a move**, because almost
everything in its commissioning section is a tolerance rather than a connection. Straight from the
manual's own "Commissioning / basic settings" (all factory-set, all explicitly to be verified or
recalibrated after installation):

| What | Tolerance / requirement |
|---|---|
| Floor | Flat, level, able to bear ~1100 kg. Centre of gravity sits **~100 mm below the saw-blade axis** |
| Swing-arm check | 0.5 mm |
| Main-table height | **0.1-0.2 mm** |
| Cross-slide height | cardboard-slip test, 0.5 mm |
| Sub-rollers | adjust |
| Free-cut setting | sliding table and rip fence, aim ~0 |
| Angle-cut calibration | test cut, 350 mm/72-tooth blade at 5000 rpm on a 1000x1000 mm board, **max tolerance < 0.2 mm** |
| 0° blade-tilt calibration | by test-cut comparison |
| Electrical | Qualified electrician; **verify main-saw motor rotation direction on first start** — swap two outer conductors if wrong |
| Extraction | Both sockets connected (top at the safety hood, bottom ø120 mm, total ø140 mm); **interlocked** to machine power via a potential-free contact or current transformer; hoses flame-retardant and antistatic; **min. 20 m/s** |

**A saw out of angle calibration cuts out of square, and under-velocity extraction is a health
issue, not a paperwork one.** Whether any of this was redone after the move is not recorded — see
Open questions. It is not assumed to have been skipped.

Note also the mechanical fault table below already contains the two symptoms a bad re-install
produces: *"Cut size ≠ fence setting"* and *"Blade burns on sliding-table side / rip-fence side"*
(free-cut wrong). If either has appeared since the move, start there.

## Installation / setup

Full detail with figures is in the main manual (parts 1-6); this is a working summary.

**Siting.** No special foundation required, but the floor must be flat, level, and able to bear
the machine's weight. Centre of gravity is ~100mm below the saw-blade axis. Foundation/space plans
vary by fence configuration (manual/motorised rip fence, crosscut/mitre fence, CNC UNO/DUO fences).

**Assembly sequence**: telescopic tube for swing arm → table-top length extension → table-top width
extension → rip fence measuring bar → cross-slide → crosscut fences (WGA, WGA_LD, DUO 90, DUO Flex,
UNO 90) → sliding table (bottom/middle/top carriage, e-chain, switch-cabinet plug — 3-pole and
5-pole connectors, colour-coded, **only connect/disconnect with the main switch off**).

**Electrical.** Qualified electrician only. Verify main-saw motor rotation direction on first start
— swap two outer conductors if wrong. Flexible supply cable must be type H07RN-F, plug per DIN
49463. Frequency-converter machines need enhanced RCD protection (named-compliant: Doepke DFS4
040-4/0.30-B NK for general protection, DFS4 040-4/0.03-B NK for personal protection).

**Extraction hookup.** Connect both extraction sockets (top at the safety hood, bottom ø120mm,
total ø140mm). Interlock extraction with machine power via a potential-free contact or current
transformer. Hoses must be flame-retardant and antistatic.

**Commissioning / basic settings** (factory-set, verify/recalibrate after install): swing-arm check
(0.5mm tolerance), sub-roller adjustment, main-table height (0.1-0.2mm tolerance), cross-slide
height (cardboard-slip test, 0.5mm), free-cut setting (sliding table & rip fence), angle-cut
calibration (test-cut procedure, 350mm/72-tooth blade at 5000rpm on a 1000×1000mm board, max
tolerance <0.2mm), 0° blade-tilt calibration by test-cut comparison.

**RAPIDO scorer blade replacement**: release clamping screw, turn spindle ~3-4 turns clockwise to
free the flange, undo torx screws, remove/replace scoring blade, clean flange and screws
thoroughly (keep dry, no dust). Fit new blade observing rotation direction and hole pattern,
tighten screws to **8.6 Nm**. **Do not apply oil or grease to this joint.** Scorer blades are
Ø180mm (front and rear) per the spare parts manual — exact article numbers weren't reliably
OCR'd, quote the machine's model/variant when ordering (see Suppliers article).

**ElmoDrive control-unit calibration**: recalibrate the relevant axis every time the saw blade is
changed — select axis, hold Cal >1s until "C" appears, enter the measured dimension from a test
cut, confirm. Same pattern for height, tilt, scorer axis, and crosscut-fence angle calibration.
Tool-change recalibration is a numbered 6-step procedure (fit blade → select in tool management →
enter/measure cutting height → hold Cal ~1s → enter measured value → press Cal).

**Remote maintenance**: the ElmoDrive control unit has a remote-maintenance access code that lets an
Altendorf technician log in — the code is printed in the ElmoDrive manual; it is deliberately **not
reproduced here**, since a published default is still a way into the machine. Screen frames red
while a technician is connected; ends on machine restart or re-entering the code.

## Safety

From the main manual and the ElmoDrive manual. Key points beyond the standard "lockout before
maintenance, PPE required, E-stop secures against restart" baseline shared with `FA2301`:

- **Mandatory monthly documented safety-device check** — not optional. The manual states outright:
  *"Carry out and document this check 1x month!"* Covers: E-stop response, sliding-table limit
  switch, plate/chip-duct limit switch, ON/OFF switch cleanliness, protective hood condition. See
  `Wiki/Processes/f45-monthly-safety-device-check.md` for how this is logged in this KB (Smartsheet
  "Safety Check Log" sheet).
- **Annual electrical check**: PTC winding-shield resistors in the motor terminal box must be
  checked by an electrician at least once a year, cold motor, expected reading 150-1000 Ω. **Note:
  the spare parts manual does not list a "PTC" component anywhere** — the closest matches are a
  "Bremswiderstand" (brake resistor) in the switch cabinet and a "Permanentmagnetbremse" (permanent
  magnet brake) on CNC-fence drive motors. The PTC resistor's exact part identity remains
  unconfirmed; this doesn't change the requirement to have it checked annually.
- **Riving knife**: must be re-checked every time the saw blade is changed (event-based, not
  calendar-based); thickness must be ≥ the main blade's thickness. The riving-knife holder itself
  is rated for blades up to Ø450mm.
- **Laser cutting-line display** (if fitted): never view the beam with optical aids; never fit
  mirrors in the laser area; never modify the optics; warning labels must stay legible; only
  Altendorf may repair a defective unit.
- **Electro-pneumatic hold-down**: crushing risk — never reach under the pressure plate; clamping
  force up to 1000N at 6 bar.
- **Tilting the saw blade**: use the wide safety hood, laterally adjust the guard for negative
  tilt angles, clear the table of workpieces in the tilt area, watch for collision with
  double-roller-carriage attachments at negative angles.
- **Machine diagnosis function groups**: Group 1 (motor temp, machine door, lower blade cover,
  E-stop, sliding-table limit switch) stops drives / prevents start. Group 2 (brake unit) prevents
  start and calls for a service technician.
- Residual risks called out: blade/scoring-blade contact (especially at -45° tilt), contact from
  beneath the table at sliding-table extremes, kickback, tooth ejection/blade breakage, crushing at
  the motor-driven sliding table/tilt/crosscut fence, live parts when the cabinet is open, hearing
  damage, dust exposure.

## Maintenance schedule

**User-level cleaning** (main manual, ch.7): four intervals confirmed — **Daily, Weekly, Monthly,
Every 6 months** — covering the machine table, sliding table (carriages, sub-rollers, guide rods),
rip fence (round rod, pivot arm, guide rollers), tilt segments, machine interior, machine
environment. Activities: vacuum/brush, clean, spray, oil ("oil, then move 20 times"). **Caveat**:
the source table's exact row-to-interval mapping was lost in OCR extraction — check the manual's
own page 155 table before treating any one pairing as authoritative.

**Detailed procedures** (with figures in the manual):
- Sliding table: clean guide/underside with a spirit-soaked cloth; clean sub-rollers.
- Round rod (rip fence): spray, then move the block up/down.
- Pivot arm: open the compartment, clean the roller (top and underneath). **Do not oil the pivot
  arm — clean dry only.**
- Cleaning agents by soiling type: chips/dust → vacuum/brush/cloth; resin → nitro thinner (general)
  or petroleum/spirit (on the sliding-table guide specifically); rust prevention → universal oil
  after cleaning. **Never apply resin remover to anodised surfaces.**

**Lubrication — trigger-based, not purely calendar:**

| Item | Interval / trigger | Notes |
|---|---|---|
| Saw-unit tilt (tilting to one side) | Display message after **100m** of height-adjustment travel, **or at least once a year regardless of distance** | Set blade tilt to 45°, cutting height to 0mm; grease at the lubricating nipple; no saw-shaft relubrication needed |
| Saw-unit tilt (tilting to both sides) / scorer | Same trigger pattern | Optional scorer lubrication point only on tilt-both-sides machines (**this machine is the two-way tilt variant, per the spare parts manual title, so this applies**) |
| Rip fence / X-axis | Move to specific "lubricating position" values (e.g. 800→805mm) and lubricate with the supplied grease gun | Machine must be off and locked out; cover removed/refitted; clear the error message after |
| CNC rip fence (DIGIT X / CNC fence) | Display message after **1500m** of travel, **or at least every 12 months regardless of distance** | Max 5 grease-gun strokes = 7g. **Over-lubricating from too-short intervals causes failures** |
| PTC winding-shield resistors | **At least once a year**, cold motor | By a qualified electrician; expected 150-1000 Ω |
| ElmoDrive central lubricator cartridge | On error E18 "Fresh oil lubricator empty" | Change cartridge |

**Approved lubricants** (main manual): Aralub HL 2, BEACON 2, BP Energrease LS 2, ELF ROLEXA 2,
Gulfcrown Grease No. 2, Marson EPL 2, Shell Alvania grease R 2, "Extreme LGEP 2" (SKF), Way
Lubricant 220 (Texaco). **Lubricants containing graphite or MoS2 additives are explicitly
prohibited.**

**Key spare/wear parts** (from the spare parts manual — article numbers are OCR-uncertain where
noted, confirm against the physical part or the online shop before ordering):
- Main saw drive belt: V-ribbed "6 PK 750."
- Scorer (2-/3-axis) drive belt: V-ribbed "3PJ-965."
- CNC-Winkelanschlag UNO 90 drive: toothed belt "10T5/260," part K3500.0135.
- CNC-Winkelanschlag DUO Flex drive: toothed belt "10T5/330mm" (66 teeth), part K3500.0076.
- Riving-knife holder: part B1480.0051, rated for saw blades up to Ø450mm.
- Saw shaft assembly: "Sägewelle F45," part B1480.0044; quick-change flange "Schnellwechselflansch
  F45-2006."
- Scorer blades (RAPIDO): Ø180mm front and rear — exact article numbers not reliably captured.
- HM main-drive belt and scorer drive belt are both listed "on request" (no fixed article number
  printed) — must be specially requested from Altendorf.
- Sub-rollers/guide rollers: swivel-arm support/guide rollers (Standard B1408.0010 / Compact
  B1408.0020M), sliding-table middle-carriage double roller B1419.0022.
- Ordering: quote the part's article number and, where relevant, the machine's model/variant —
  see `Wiki/Suppliers/altendorf-gmbh.md` for the shop/phone/email contact. **No PTC resistor and
  no F1/F2/F8/F9/F15/F16 fuse cross-reference exists in the spare parts manual** — these remain
  unidentified by part number.

## Fault diagnosis

**Mechanical fault table** (main manual, ch.8):

| Symptom | Cause | Fix |
|---|---|---|
| Machine won't switch on | Main switch off / power or phase failure / overload protection tripped | Switch to "I" / restore supply, check factory fuses / let motor cool, check diagnosis display |
| Machine switches off during operation | Sliding table over blade centre line / E-stop pressed / door or base plate open / control-circuit fuse (F1, F2 or F8) blown / phase failure | Move table back / rearm E-stop / close door or plate / replace fuse with same rating only / fix supply phase |
| Workpiece jams while feeding | Overload tripped (blunt blade or excess feed) / fuse blown / blunt blade / wrong riving-knife thickness | Change blade or reduce feed, let motor cool / replace fuse / fit sharp blade / fit correct riving knife (≥ blade thickness) |
| Break-outs despite scorer | Feed too low / too many teeth on blade / incorrect free cut / scorer misaligned / scoring blade too narrow / blunt scoring blade | Increase feed / change blade / readjust free cut (aim for ~0) / readjust free cuts / adjust saw width / exchange scoring blade |
| Workpiece rises when cut with scorer | Cutting height too low | Set the scoring blade higher |
| Cut size ≠ fence setting (rip or crosscut) | Dimension scale misadjusted / DIGIT X calibration wrong | Reset via test-cut and measure / recalibrate |
| Pivot arm doesn't move smoothly | Soiled telescopic tube/track rollers | Clean, check wiper |
| Sliding table has lateral play / sits proud at end positions | Sub-rollers incorrectly set | Set the sub-rollers |
| Blade burns on sliding-table side / rip-fence side / both | Free-cut setting wrong (insufficient / excessive / both) | Readjust free cut on the relevant side(s) |
| Workpiece has burn marks | Jammed workpiece / operating error (guided on rip fence while using sliding table) / blunt blade | Fit riving knife correctly or use a wider one / guide at LH or RH fence only / change blade |
| No air to air-cushion table | Insufficient supply / solenoid valve stuck / TPL/TPV not supplied / fan not working | Check 6 bar supply and hoses / electrician checks coil / check fuses / electrician checks fan |
| No air cushion forms | Ball roller leaking / excess pressure / brush too high | Push ball down or replace roller / lower pressure / lower the brush |

answer: this saw takes dimensions, not cut lists** — to be confirmed against the control's own menus
before being recorded as fact. This matters for the SmartCabinet hand-off: the optimisation output
is most likely consumed by an operator on screen or paper, not imported.
